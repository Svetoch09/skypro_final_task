Система контроля версий Git

  • git config --global user.name "USER NAME" – Задать или изменить имя пользователя
  • git config --global user.email "user@mail.com" – Задать или изменить email
  • git init – Создать пустой репозиторий Git
  • git status – Проверить статуса репозитория
  • git commit -m "Message" – Внести изменения c однострочным сообщением
  • git log -p – Просмотреть историю коммитов с изменениями
  • git show 1af17e – Просмотреть заданный коммит с хэшом 1af17e
  • git diff – Просмотреть список изменений, внесённых в репозиторий, но не подготовленных для фиксации
  • git mv – Переименовать файл
  • git revert – Откатить последний коммит
  • git branch new_branch_name – Создать новую ветку
  • git checkout new_branch_name – Перейти в новю ветку
  • git branch – Просмотреть список веток
  • git branch -d existing_branch_name – Удалить ветку existing_branch_name
  • git merge existing_branch_name – Объедиить существующую ветку existing_branch_name с основной
  • git merge --abort – Остановить слияние при конфликте
  • git push origin main – Отправить изменения в remote репозиторий
  • git pull – Получить изменения из remote репозитория
